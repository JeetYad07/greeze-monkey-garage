# Greeze Monkey Garage — Design System Master Specification

## 1. Visual Direction: Warm Premium Automotive
- **Core Personality**: Premium Independent Automotive Workshop + Editorial Photography + Modern Local Trust + High-End Craftsmanship.
- **Tone**: Sophisticated, human, confident, established, tactile, transparent, engineered without looking sterile or robotic.
- **Anti-Patterns Strictly Avoided**:
  - No generic dark mechanic template.
  - No 3x3 dashboard card grids on every section.
  - No excessive icons on every sentence.
  - No purple/blue AI gradient blobs.
  - No pill button overload or 24-32px border radii.

---

## 2. Color Tokens & Semantic Hierarchy (70% Warm Light / 20% Dark Graphite / 10% Burnt Orange Accent)

| Token | Hex / Value | Semantic Role |
|---|---|---|
| `--color-bg` | `#F7F5F0` | Warm parchment / ivory primary background (70%) |
| `--color-card` | `#FFFFFF` | Crisp clean surface for focused containers |
| `--color-text` | `#17191A` | Deep charcoal high-readability body & headings |
| `--color-dark` | `#202426` | Dark graphite for Proof of Work, Final CTA, dark accents (20%) |
| `--color-dark-surface` | `#2A2F32` | Dark card/step background inside dark graphite sections |
| `--color-accent` | `#D97732` | Burnt orange / terracotta — primary CTA, step markers, active links (10%) |
| `--color-accent-light`| `#F0B27A` | Subtle warm orange highlight / tint |
| `--color-muted-green`| `#66705F` | Secondary natural olive/green for verification ticks |
| `--color-muted` | `#6B6D69` | Editorial secondary text & metadata |
| `--color-border` | `#DDD9D0` | Hairline warm borders |
| `--color-border-dark` | `#353B3E` | Hairline dark borders for graphite modules |

---

## 3. Typography
- **Headings**: `Manrope`, sans-serif (Weights: 500, 600, 700, 800). Sentence case preferred.
- **Body / UI**: `Inter`, sans-serif (Weights: 400, 500, 600).

---

## 4. Layout & Spacing
- **Editorial Rows**: Used for Services instead of card grids.
- **Editorial Asymmetric Grid**: Used for Gallery (70% hero image, 30% stack, 2 medium, 1 full-width).
- **Border Radius**: Restrained 6px, 8px, 10px (max 12px).
- **Shadows**: Minimal to none; structure established with borders, whitespace, and photography.
